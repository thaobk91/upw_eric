reset the system - hot reset
if "delay" in second, is not specified, it is =0 and reboot is immediate 
{"msg":"reset", "delay":120}     

request configuration 
{"msg":"config"}    

clear the log
{"msg":"rstlog"}    

request error report and clear error count
{"msg":"errorlog"}   

update the firmware with the binary file "blink" in the example bellow
if "version" is left out the message, uses the default file name "latest" to update the firmware
{"msg":"update", "version":"blink"}   

update the config.json file
{"msg":"json", "name":"AM-6003"}

request gps report
the gps coordinate is acquired at boot
at boot, the system will attempts to acquire the position 10 times before giving up and resuming operation
the data is valid when the date, time are correct and lock_gps = true
{"msg":"gps"}

set the correction offset to the temperature sensor 
{"msg":"caltemp", "offset":-3.2}

switch ON / OFF the engineering mode
in this mode the reading from the senors are reported in volt instead of ppm
{"msg":"eemode", "command":1}
{"msg":"eemode", "command":0}
